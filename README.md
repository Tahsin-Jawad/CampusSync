# 🚀 CampusSync

**CampusSync** is a modern, real-time peer-to-peer (P2P) platform designed to help students streamline their academic routines, track live campus statuses, and effortlessly connect with peers who share free time. 

Whether you are managing tight assignment deadlines or looking to see which of your study partners are free on campus right now, CampusSync keeps everyone connected.

---

## ✨ Key Features

* **📅 Smart Routine Management:** Easily import academic advising slips or routines via `.xlsx` files or add courses manually with an intuitive schedule grid.
* **🟢 Live Status Tracking:** Toggle your availability status instantly (`ON_CAMPUS` / `OFF_CAMPUS`) so your peer network knows when you're available.
* **👥 Free Friends Finder:** Automatically match schedules in real-time to see which friends or group members currently have free periods.
* **🔗 P2P Connectivity & Collaboration:** Share direct communication lines, quick contact numbers, and coordinate group activities smoothly.
* **🔒 Secure Authentication:** Powered by Firebase Authentication and Firestore for fast, secure, and reliable real-time data synchronization.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite
* **Styling:** Tailwind CSS, DaisyUI
* **Backend & Database:** Firebase (Authentication & Cloud Firestore)
* **Utilities:** SheetJS (`xlsx`) for parsing schedule spreadsheets, Lucide React for UI icons
